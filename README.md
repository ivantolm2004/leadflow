# LeadFlow

Демонстрационный интерфейс системы обработки заявок для малого бизнеса. Проект показывает, как обращения из разных источников можно собрать в одной панели, приоритизировать и передать менеджеру без ручного копирования данных.

## Что умеет демо

- показывает ключевые метрики продаж;
- фильтрует заявки по статусу;
- имитирует получение новой заявки в реальном времени;
- адаптируется для телефона, планшета и компьютера;
- работает без сборки и внешних зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера можно использовать любой статический сервер.

## Возможности коммерческой версии

- приём заявок через REST API и веб-формы;
- хранение в PostgreSQL;
- уведомления в Telegram и email;
- интеграция с amoCRM, Bitrix24 или HubSpot;
- роли пользователей, авторизация и журнал действий;
- Docker-развёртывание и автоматические тесты.

## Стек

HTML5, CSS3, JavaScript. Демо намеренно не использует фреймворки: оно быстро загружается и легко запускается заказчиком.

## Автор

Портфолио-проект разработчика автоматизаций и AI-интеграций.
